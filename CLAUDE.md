# Instructions for Claude Code

This repo uses `AGENTS.md` as the canonical guide for AI coding agents,
so that the same rules apply whether you're running Claude Code, Codex,
or any other agent.

**Read `AGENTS.md` at the start of every session.** Treat its contents
as binding instructions. Read `README.md` for project background.

When conventions need updating, edit `AGENTS.md` — do not add overrides
here.
